# acnh-furniture-spatial

## 步骤
1. 关联 ItemParam 尺寸候选 0xE06FB090 与 ItemSize 的标签、ID、宽高。28 条尺寸定义是当前基线，逐物品仍待实测。
2. 原始宽高为半格值；保留整数原值，展示时除以 2。地面宽深与墙面宽高分离，地毯、柱子、天花板分层。
3. 在 3.0.3 原始字段和实际样本确认 ItemLayout 候选；历史标签 Floor_Downer、Floor_Upper、部分承载面仅作为线索。
4. 分离矩形尺寸、承载面掩码、真实支撑点、碰撞形状、通行、旋转锚点、高度、交互点；不可用矩形推导堆叠容量。
5. 检查资源文件与运行时消费者；记录正常/旋转/不可摆放/多层/边缘样本；未知行为输出 null 与证据状态。
## 交付
原生尺寸字典、逐 ID 空间属性、承载/碰撞关系、反例、可复现测试与专题文档。模拟器示意不得称为游戏真实行为。
