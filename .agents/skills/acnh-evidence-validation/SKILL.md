# acnh-evidence-validation

## 步骤
1. 检查当前 branch/commit，固定输入 SHA256、脚本版本、命令、工具版本、样本与分母。
2. 建立可执行断言：源文件、边界、唯一 ID、行数、类型、缺口、差异；防止静默默认和重复计数。
3. 按需运行本地测试或 GitHub Actions；读取实际运行 ID、job 日志、结论和产物（若可访问）。push 成功、无状态、空日志不算通过。
4. 区分 PASS/FAIL/NOT_RUN/BLOCKED，另列源版本差异及语义未证实项；如 CI 返回失败，记录具体失败步骤。
5. 输出机器可读报告与简明摘要；核对原始 NCA tree 不变；若无运行权限，明确待验收。
## 证据分级
原版字节（结构/值）、第三方源码（兼容行为）、原生消费指令（业务行为）、运行时实测（指定样本）、历史/候选（非当前版本结论）。这些是不同证据维度，不以一个等级替代另一个。
