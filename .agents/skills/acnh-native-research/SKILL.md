# acnh-native-research

## 步骤
1. 固定目标版本、模块 SHA256、分析工具版本、映像基址和地址换算；区分 VA、RVA、文件偏移、运行时地址。
2. 从原始指令、函数边界和交叉引用确认候选函数；区分反编译伪码与真实机器码，不靠函数名猜语义。
3. 记录读取/写入宽度、偏移、条件、调用者/被调者、数据流与可复现样本；有证据再命名。
4. 优先静态与测试环境验证；运行时实验须得到授权，记录输入与结果，不改原始资源或线上账户。
## 交付
固定地址/指令范围、证据引用、字段字典更新、未解决分支与复现步骤。原版字节、源码和运行时证据分别列明。
