# 保存管理器与玩家、村民动态根

> [!update] 后续验收见 [[08-保存管理器生命周期与Friendship静态验收]]（[GitHub 阅读](08-保存管理器生命周期与Friendship静态验收.md)）：R100 真实 SQLite 已确认 RELR 别名，注册及注销已恢复，Friendship 相对记录 +0x46 获得静态证据。本页保留历史研究阶段原文。

## 证据范围

本轮实际读取 3.0.3_Unpack 的 Ghidra C 导出；使用 0x100000 slide 换算 RVA。没有重新取得认证 ELF、实机快照或 R100 SQLite。以下为静态反编译语义，不能自动标为 runtime_verified。原始符号名称及全局槽段属性尚未确认。

## 1. 共享保存管理器根候选

Ghidra DAT_05574040 → Main RVA 0x5474040。FUN_0264d510、FUN_0265c2a0、FUN_0265cf70、FUN_0265e000 均读取该槽。PTR_DAT_04bb46b0（RVA 0x4ab46b0）在 FUN_007e2520 等函数中执行相似对象访问；两者是否指向同一槽必须经 R100 证明。

|对象字段|观察到的用途|
|---|---|
|+0x10|后端对象/指针表|
|+0x453 bit0|后端选择|
|+0x20|背包访问器的备用描述符|
|+0x90..0xcc|八组索引及有效状态，普通玩家访问分支|
|+0xd0..0x10c|另一组八项索引及状态|

归纳伪代码（虚调用不可当普通指针解引用）：

```cpp
M = global_DAT_05574040;
if (!M) return null;
T = read_ptr(M + 0x10);
if ((read_u8(M + 0x453) & 1) == 0) {
    // 原导出在此分支未显式检查 T
    v = virtual_call_0x38(read_ptr(T));
    return v ? v + 0x70 : null;
}
if (!T || !read_ptr(T + 0x130)) return null;
return virtual_call_0x38(read_ptr(T + 0x130));
```

源： [0264d510](../../derived/3.0.3/ghidra12.2/c/d5/0264d510.c)（blob 2b08f7535526d1c381cf52191f3adf9dd3e3f6f3）。其 0x26 个 u64 元素应换算为 0x130 字节。真实构造/注册/析构及虚函数目标尚未定位。

## 2. GSaveNpc 相关访问路径

FUN_0265c2a0 在村民索引 0..9 范围内形成 B + i*0x10798 + 0x118 的描述符；描述符 +8 与 +0x10 两个字段相加才得到数据地址。+0x28 是回调/守卫相关字段（原类名未定）。函数另外检查物种与序号有效性。

FUN_0265cf70、FUN_0265e000 独立交叉印证两个关系记录分支：

|分支|描述符地址|索引限制|
|---|---|---|
|A|B + npc*0x10798 + relation*0xa8 + 0x39f8|npc < 10，relation < 160|
|B|B + npc*0x10798 + relation*0x700 + 0x1c0|npc < 10，relation < 8|

B 是 FUN_0264d510 语义对应的后端数据返回值。FUN_0265cf70 通过 FUN_021d74d0 与 FUN_021d7030 从玩家身份映射关系索引；并非直接用玩家槽号。FUN_021d74d0 实际循环 160 条身份记录，身份记录步长 0x158（0x2b 个 u64）；与上面的 0xa8 描述符步长不同。

原工具 GSaveNpc 固定 Heap 步长 0x13230 不能直接替换为 0x10798，后者属于原生描述符布局而非已经证明的序列化记录布局。

来源：[0265c2a0](../../derived/3.0.3/ghidra12.2/c/c2/0265c2a0.c)、[0265cf70](../../derived/3.0.3/ghidra12.2/c/cf/0265cf70.c)、[0265e000](../../derived/3.0.3/ghidra12.2/c/e0/0265e000.c)、[021d74d0](../../derived/3.0.3/ghidra12.2/c/74/021d74d0.c)、[021d7030](../../derived/3.0.3/ghidra12.2/c/70/021d7030.c)。

## 3. Friendship 原生读取已恢复到字段查找

FUN_00baab34 case 2 将字面量 Friendship 传入 FUN_02746c30，后者调用 FUN_0265cf70 获取关系描述符 R。实际读取逻辑为：

```text
payload = u64(R+8) + u64(R+0x10)
key = FUN_006bd550(field_name, 0)
metadata = FUN_020f3140(P(PTR_DAT_04bb2208)+0x220, &key)
在 metadata 的字段表中查找 0x54706054
offset = metadata 所提供的 u16（有效时 <0x100）
返回 u8(payload + offset)
```

缓存 PTR_DAT_04bb6360 内保存查找结果，-1/-2 属于特殊状态。实际控制流含回调获取/释放与错误分支；上面仅归纳成功路径。0x54706054 是元数据键，并非 Friendship 名称哈希已证实。工具历史 +0x46 仍未被真实字段表解析或实机读值确认。不能以通用访问器证明固定偏移。

来源：[00baab34](../../derived/3.0.3/ghidra12.2/c/ab/00baab34.c)、[02746c30](../../derived/3.0.3/ghidra12.2/c/6c/02746c30.c)、[020f3140](../../derived/3.0.3/ghidra12.2/c/31/020f3140.c)。

## 4. GSavePlayer 相关访问路径

FUN_007e2520 经 PTR_DAT_04bb46b0 取得管理器，再调用 FUN_026eec4c 获取玩家对象；随后读取 UpgradePocket40/UpgradePocket30，迭代 20/30/40 个背包槽并调用 FUN_026759e0。由真实消费者确认该返回对象与玩家数据有关。

FUN_026eec4c 的两个分支：
- bit0=0：FUN_026eed64；验证玩家索引/身份记录，遍历 manager+0x90 起八组 (id,active)，匹配槽 k 后取 P(P(manager+0x10)+0x60+k*8)，返回该对象 +0x20 的指针。
- bit0=1：通过后端 +0x130 虚调用取得数据，校验索引 0..7 的身份记录（步长 0x48），再取 P(P(manager+0x10)+0x140+index*8)，返回对象 +0x10 的指针。

FUN_026759e0 背包消费者：
- 描述符 D = player+0x194b0；若 P(player+0x194b8)==0，改用 P(DAT_05574040 指向对象+0x20)。
- payload = u64(D+0x78)+u64(D+0x80)。
- 第一访问区 payload+0xb8+slot*8，容量来自 payload+0x158（最多20）；另一区 payload+slot*8，容量来自 payload+0xa0（最多20）。
- 原函数执行边界、ItemID 及空值检查。未证明此布局与固定 Heap 0xB27BB758 或原工具 0x131F70 步长对应。

来源：[007e2520](../../derived/3.0.3/ghidra12.2/c/25/007e2520.c)、[026eec4c](../../derived/3.0.3/ghidra12.2/c/ee/026eec4c.c)、[026eed64](../../derived/3.0.3/ghidra12.2/c/ed/026eed64.c)、[026759e0](../../derived/3.0.3/ghidra12.2/c/59/026759e0.c)。

## 5. R100 关联及验收

R100 当前 xrefs 只索引原有 GLOBALS 与字符串目标，不是所有全局槽的完整代码索引。已有 SQLite relocation 表可先查询 0x5474040 与 0x4ab46b0 两个 RVA 的直接/反向重定位，再在认证 ELF 中针对新地址扩展引用扫描。不得以 xrefs 空结果判定全局不存在。

```sql
SELECT * FROM metadata;
SELECT * FROM relocations
WHERE slot_va IN (0x5474040,0x4ab46b0)
   OR target_va IN (0x5474040,0x4ab46b0)
ORDER BY slot_va;
```

验收：原始 ELF 指令字节、段属性、全局注册与清零、虚表 +0x38 真实目标、描述符实际数据、元数据 Friendship 偏移、两次离线快照。不能执行虚函数或写内存来替代只读证据。两个根引用的同一性及保存管理器正式名称仍待证明。
