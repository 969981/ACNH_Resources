## 3. 第三类工厂原始窗口

FactoryAudit/itemlayer_constructor_windows 共27项（11+3+3+10），其中第三类012CF530的3处调用：
|入口候选|site|分配尺寸|证据|
|---|---|---:|---|
|012CF488|012CF510|0x1AEC8|序言、分配、调用、返回均在原始窗口|
|未闭合|012D4AD4|未知|复杂分支，仅尾部窗口|
|012DB97C|012DBA08|0x1AEC8|序言、分配、调用、返回均在原始窗口|

前两种已恢复的简单工厂分别由012CF488..012CF524与012DB97C..012DBA1C组成，入口身份仍待独立原始CFG复核；两者均使用 W1 组合立即数0xAEC8和高16位1，分配0x1AEC8（110280）字节；构造前将描述符传入X1。原始指令：
|VA|bytes|instruction|
|---|---|---|
|012CF4B4|01d99552|mov w1,#0xaec8|
|012CF4B8|2100a072|movk w1,#1,lsl #16|
|012CF510|08000094|bl #0x11cf530|
|012DB9A4|01d99552|mov w1,#0xaec8|
|012DB9A8|2100a072|movk w1,#1,lsl #16|
|012DBA08|caceff97|bl #0x11cf530|

描述符有三个连续标志字节，第一处窗口为01 01 00，第二处为01 01 01；具体业务命名未验证。012CF530 C中存在对应的条件分支，但不得据此推定两类实际场景身份。复杂调用012D4AD4前可见另一分支直接调用012E4640（site 012D4ABC），两条路径汇合于012D4AD8。尚缺该函数入口与分配尺寸的可靠数据流；不将最近C导出_INIT_4405误认作函数所有者。

## 4. 八层快照刷新

01259024 本轮200条匹配指令，唯一gap为预算边界VA01259344。已覆盖八处直接调用012E4B00以及24处间接调用site；每层先检查对象、接口条件及返回对象非空，然后依据选择值在两个工作描述符间选择，超界回退首个描述符。最后原始0125933C MOV W0,#1（20008052）已匹配；C证据支持返回1，但实际RET尚需补齐预算。它不表示每层均刷新成功，也不表示保存事务完成。
