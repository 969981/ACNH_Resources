- [02542D18](../../derived/3.0.3/ghidra12.2/c/2d/02542d18.c)：身份/对象检查及记录转发，调用024BF968；不能认定为 Field 写入。

## 4. SelectCursor 构造验收

[03200224](../../derived/3.0.3/ghidra12.2/c/02/03200224.c)，blob 62e27be4aa650362729f7727f14f016e233945a9，原始字节匹配导出74行无gap。结合上一轮03387C94分配0x288。

|偏移|观察|
|---|---|
|+0|PTR_LAB_04B0EA80 虚表候选|
|+0x1F8|u8 身份字节，来自配置+0xE，超范围归一FF|
|+0x1FC|配置+0x10的u32|
|+0x230|内部字符串缓冲区指针，指向自身+0x23C|
|+0x238|容量0x20|
|+0x23C|内嵌缓冲区|
|+0x260|初始化为2的8字节字段|
|+0x27C|初始化为两个float 1.0 的位模式|

SelectCursor 是独立 UI 组件。尚无证据说明它直接持有背包逻辑槽位。构造中身份字段、字符串索引、图形参数与背包索引不得混用。UIComponentOwner Main 根、发布和注销尚未确认。
