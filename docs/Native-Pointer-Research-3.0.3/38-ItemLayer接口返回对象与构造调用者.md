三个接口首项回调均读取接口自身+8保存的owner，再返回owner内嵌对象，而非直接返回数组：

|VA|bytes|instruction|
|---|---|---|
|012CAF84|080440f9|ldr x8,[x0,#8]|
|012CAF88|00c13a91|add x0,x8,#0xeb0|
|012CAF8C|c0035fd6|ret|
|012C8008|080440f9|ldr x8,[x0,#8]|
|012C800C|09469052|mov w9,#0x8230|
|012C8010|0001098b|add x0,x8,x9|
|012C8014|c0035fd6|ret|
|012D05A4|080440f9|ldr x8,[x0,#8]|
|012D05A8|08494091|add x8,x8,#0x12,lsl #12|
|012D05AC|00c10891|add x0,x8,#0x230|
|012D05B0|c0035fd6|ret|
|012AC290|20008052|mov w0,#1|
|012AC294|c0035fd6|ret|

第三类计算0x12000+0x230=0x12230。上述仅确认接口返回的子对象身份和共同返回1的回调。实际网格数据所有权及后续虚调用语义不能由此自动得出。三个+8回调均因上轮0x10预算截断；已扩展至0x180，待新CI验证。

## 4. 八层快照刷新
