R100 04B23810/+8/+0x10 目标分别为 00CC424C / 03390A64 / 0338B5CC；+0x18 暂未得到 relocation，不能用默认表硬解实际运行时回调。0338B5CC C blob a0ef8c937c300fdbe4253b29e98e3aeecb041098 将参数对象+0x10/+0x18/+0x20 清零，+0x28=1，+0x2C=0。

00C04EE0、00C31AE0、00D97E30、00DD7A70 均从 GOT Main+0x4AB2230 取根，再经 +0x28 读取 D78/D90 并写 D79。前三个入口不把自身偏移 D90 当作位图。四条路径共有行为：若 D78 非零，调用 (shared+D70) 的 vtable+0x18，然后清 D78；否则结果为1；D79=结果&1。D79是缓存的低位结果，不能命名为确认键、取消键、可投放状态或联机成功。

## 6. 业务上下文

[010B9ADC](../../derived/3.0.3/ghidra12.2/c/9a/010b9adc.c) blob 4d1dc1de7a89841da72520e05af97af5fd914bda：原生字符串 cItemSelect 与 cPresentItem 比较；模式1消费共享+0x2C物品，其它分支消费 D90 位图、popcount 后逐槽容量校验与读取，并调用自身 vtable+0x38。独立支持共享结果供业务选择消费。[00B47010](../../derived/3.0.3/ghidra12.2/c/70/00b47010.c) 模式0xD遍历 D90 的置位槽，模式其它读单件+0x2C；[00DBEC80](../../derived/3.0.3/ghidra12.2/c/ec/00dbec80.c) 读 D90 并清零重置。不能将所有共享选择消费者等同于普通地面丢弃或原生赠礼。

00D982B0 的上轮 CFG 首段从 self+8 取对象，self+D8 低16位构造本地物品记录，调用0277D4AC，检查 self+128 byte 后分支；后续既按物品又按槽扣减。这些都是静态字段消费，完整业务类名未确认。五个入口对应同型重定位表，比直接文本 XREF 更强；当前未定位上游注册名/调用者。生产代码和正式 Build ID 指针库保持不变。
