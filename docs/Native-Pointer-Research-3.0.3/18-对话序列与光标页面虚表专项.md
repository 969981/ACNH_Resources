## 6. EventFlow 与逻辑槽位分离

[00ADA9C4](../../derived/3.0.3/ghidra12.2/c/a9/00ada9c4.c) blob e186ad40e99ffad098228ea2be0ca26aa5fddfd5 注册 Reaction、PlayerAutoEnd、MessageID、Frame、Continue 参数描述符。MessageID 字符串标签位于 self+130，Frame标签位于+160，Continue标签位于+188；它们是该参数注册对象内的标签地址字段，并非消息窗口实时值。尚未证明此函数所属具体 EventFlow action 或机场消费者，不能将标签字段代替 ChatId。

PocketMenu vtable +0/+8 对应 03197688/031977EC，实际读取 C 后确认前者为类型描述符比较、后者返回类型描述符，并非背包 index getter。旧 Heap 光标仍未映射；后续需区分页面焦点、菜单条目索引、物品逻辑索引及物品记录。

## 7. 验收状态

本轮确认三条 RELR、135 个有限范围槽记录及上述 C 数据流。未获取实时内存、原始新增指令、0x7000 分配因果；不改变生产指针。新增 ELF 入口后以原始字节验证间接调用及字段宽度，再进行自有离线 UI 快照差分；实际 ChatId/IsChatEnded/TextSpeed/背包高亮字段一律保持 null。对话序列索引也不能作为机场会话完成证据。
