## 4. TalkSeq predicates

02FA2DE4(+E8): 若 self+1F0 或+1F4 不等于 FFFFFFFF 则 false；否则调用 self vtable+220 取得对象 Q，Q 非空且 U32(Q+48)∈[3,7] 则 false；否则返回 U32(self+1B0)<2。
02FA2E50(+F0): Q=self.vcall220(); 若 Q 非空且 Q.vcall148(0) bit0=0 返回 false，否则返回 U32(self+1B0)<2。
