关联 [[60-R128-Savefile-Index]]。R128 最终三个 CI 通过，固定 Artifact 14897705515 SHA256 a039bf0d6c14b50e460e237f0aafe1cf6036997af6f53ea55320d84421c9d62d。

## 源码恢复
028C871C 创建 0x30 资源描述对象，基础索引0..4分别写 +60..+80，索引5写+90（版本字段分别>70005、>70000），索引6写+88（>80084、>80008）。每项调用027B6C14并检查+2C=1；不是云岛磁盘调用证明。
028C8A30 创建0x98事务对象，输入 index 超过9时类型查找回退0，通过 027B78B0、027B7AD4 获取描述，保存原始 index，调用028B5FF0。后者先读取 Header，再读取 Data，然后调用028B63C0（源码有 nn::crypto::DecryptAes128Ctr）。读取函数与具体 Cloud 消费者仍有区别。没有执行真实文件读取或解密。
Profile mode1 从 context+0x188+slot*4+1..3 检查三字节，零则内联 MurmurHash3，非零则清零0x23020；外层同样内联。待原版局部指令仿真。

- 028C6CA0..028C6CC8：原版常量寄存器初始化（终点不含）。W26=0x23018，W28=0xE6546B64，W20=0xCC9E2D51，W22=0x1B873593，W24=0x16A88000。
- 028C6D14..028C6D34：原版 slot 选择，028C6D2C ADD X9,X10,X23,LSL#2；028C6D30 CSEL X21,X9,X10,LO。合成 X25=context+0x188，经8个槽位测试 flagptr=context+0x188+slot*4。
- 028C7358..028C7674：合成栈及数据指针，执行实际内联 Hash/条件清零及下一事务参数。每块标志读取 028C735C/7424/74EC；清零 BL 028C7370/7438/7500；内层 Hash STR 028C7410/74D8/75AC；外层 STR 028C7670。仅模型化外部 memset 04004450，检查参数。
- 在 028C7674 BL 028CB2A0 之前停止：X0=合成事务参数、X1=Profile、X2=Header、X3=0x69560、X4=1、X5=4、X6=slot。80项全部匹配。不将分段原版执行解释为完整 028C29B0 或磁盘写入。
