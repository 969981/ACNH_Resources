## 如何解读单字段
字段字典中每行有：原版 `hash_XXXXXXXX`、行内偏移 `offset`、宽度提示 `width_hint`、可确认的名称和类型、简体中文解释、证据级别。

解析器目前的 `width_hint` 是“下一个独立列偏移减当前偏移”，**只是存储切片宽度**；有时是对齐/填充、字符串容器，不能简单把 4 字节都当 `u32`，更不能把 `s16=-1` 当作 65535 件。
