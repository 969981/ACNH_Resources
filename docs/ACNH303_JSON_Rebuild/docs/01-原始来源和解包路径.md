# 01 · 原始来源和解包路径

这两份多语言 JSON 是旧网站按游戏资源组装的衍生数据库，不是 ROM 中的原生同名文件。

| 来源资源（RomFS 1） | 用途及现有成果 |
|---|---|
| Bcsv/NmlNpcParam.bcsv | 417 位普通村民，ResName 为 hash_48EF0398 |
| Bcsv/SpNpcParam.bcsv | 74 条特殊 NPC，不能混入 417 普通居民 |
| Bcsv/ItemParam.bcsv | 11,178 物品；107 字段；每行 548 字节 |
| Bcsv/ItemKind.bcsv | 189 类；堆叠字段 hash_4C9BA961 是 s16 |
| Bcsv/RecipeCraftParam.bcsv | 924 条 DIY 配方 |
| Bcsv/ItemRemake.bcsv | 原生改造信息；不是网页每一个 variations 标签的直接证明 |
| Bcsv/ItemClothGroup.bcsv | 服装组名称的关联来源 |
| Message/String_locale.sarc.zs | 14 种语言/地区，每份 133 个 MSBT |

真实 ROM 根路径：e10617820db06889e1638499478da0de_NCA/1/。已解码 CSV 和字段说明位于 UnPack/1/Bcsv/。

## 解码管线
~~~mermaid
flowchart TD
  A[原始 BCSV] --> B[parse_bcsv / CRC32 字段]
  C[String_locale.sarc.zs] --> D[Zstd decompress]
  D --> E[SARC members]
  E --> F[MSBT LBL1 与 TXT2]
  B --> G[原生 SQLite]
  F --> G
  G --> H[按原版 ID / ResName / locale 对旧 JSON 对账]
~~~

实际解析函数位于 Scripts/acnh_formats.py；R76/R77/R80/R81/R82/R84 已存在。MSBT 的原文与去控制码后的展示文本必须分开保留，特别是 U+000E 内联指令。

## 村民精确链接
NpcNmlAnt00 → ant00 → Npc/STR_NNpcName.msbt 的 ant00 → 简中“阳明”、繁中“陽明”、日文“さくらじま”、英文“Cyrano”。

旧 villager 的 nameCN/TW/JP/En 对应 **CNzh/TWzh/JPja/EUen**。对旧英文按 USen 核验，会在 Jakey/Jacob 与 Crackle/Spork 出现两例地区差异。

## 物品精确链接
ItemParam UniqueID=hash_54706054；ResName=hash_3FEBC642；原始细类=hash_FC275E86。物品命名首先查 Item/STR_ItemName_*.msbt 的五位 ID 后缀；服装还需查 Outfit/GroupName/STR_OutfitGroupName_*.msbt。旧商品 name_enEU 对应 EUen。
