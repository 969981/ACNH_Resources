# 03 · 旧 JSON 与原版导出 CSV 的实测结果

> [!important] 证据范围
> 此次直接对账的是 **用户上传的两个旧 JSON** 与此前从 3.0.3 BCSV/MSBT 构建的 ACNH_3.0.3_Items.csv / ACNH_3.0.3_Villagers.csv；后者是既有衍生 CSV，并非本次重新从 ROM 二进制独立导出，亦非本次直接连接 R82 大型 SQLite。

## 英语地区更正
| ResName | USen | EUen = 旧 JSON |
|---|---|---|
| NpcNmlBrd11 | Jacob | Jakey |
| NpcNmlPig05 | Spork | Crackle |

因此此前认为旧村民 nameEn 源于 USen 的结论应更正为 EUen。

## 物品多语言并非 10,789 全部字面一致
原生衍生导出有名称的旧非 DIY 共有 10,479，另有 310 条无原生展示名。CNzh 5,687 相同，TWzh 5,288，JPja 5,241，EUen 5,287；服装组基础名与旧站带颜色/款式的展示名不能直接判为错误。严格的 MSBT 五位数字 ID 证据组有 5,315 条，其中简繁中各 27 个不等、日文 74 个不等（含赝品后缀与种子名称差异）。

另外：旧 ItemKind 对比 63 处不同，绝大部分为候选类或原始哈希，不等于 63 个原版错误。ID 1301 DreamGlold 的旧 max_stack=1，与已验证原生类别候选容量 10 有冲突，需进一步追查实际使用语义。
