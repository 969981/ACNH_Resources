# 07 · 从原始 ROM 到可读数据：格式、偏移与读取

## 1. 真正的输入与依赖

ROM 根：`e10617820db06889e1638499478da0de_NCA/1`；五个 BCSV 位于 `Bcsv/` 下，14 个本地化压缩档位于 `Message/String_{locale}.sarc.zs`。仓库脚本：`Scripts/acnh_formats.py`、`Scripts/unpack_acnh.py`、`Scripts/mirror_unpack.py`。Python 3.10+、Zstd：`py -m pip install zstandard`。

## 2. BCSV 结构

此分支的 BCSV 使用 **VSCB** 容器。仓库实际解析（`parse_bcsv`）按 little-endian：

| 偏移 | 长度 | 作用 |
|---|---:|---|
| `0x00` | 4 | 行数 `row_count` |
| `0x04` | 4 | 每行字节数 `row_size` |
| `0x08` | 2 | 列数 `column_count` |
| `0x0C` | 4 | `VSCB` 魔数 |
| `0x1C + 8*i` | 4 | 第 i 列 CRC32 字段哈希（原生无文字名） |
| `0x20 + 8*i` | 4 | 第 i 列在一条记录内的相对偏移 |
| `0x1C + 8*column_count` | `row_count*row_size` | 记录数据区 |

记录的首 4 字节是 `_row_offset_raw`（原始前缀值），**不是**自动认定的整个文件绝对偏移。解码器输出 `_row_index`、`_row_offset_raw`、`hash_XXXXXXXX`。对于 width_hint=1/2/4/8，现有读器默认按**无符号 little-endian 原样导出**；`s16`、`s32` 和浮点必须在有类型证据后再按原始字节解释；宽字节窗口可能是 null 结束的 UTF-8 文本，也可能是未知原始数据。

```python
from pathlib import Path
from acnh_formats import parse_bcsv
meta, rows = parse_bcsv(Path("e10617820db06889e1638499478da0de_NCA/1/Bcsv/ItemParam.bcsv").read_bytes())
print(meta["row_count"], meta["row_size"], meta["column_count"])
print(rows[0]["hash_54706054"])  # 原版物品 UniqueID 的原始 u16 十进制文本
```

## 3. 哈希名为何不能简单猜

BCSV 某些字段名称哈希符合 `CRC32("Name Type")`。例如：
```python
import zlib
for s in ("UniqueID u16","Material1 u16","Item u16","ItemUniqueID u16","MultiHoldMaxNum s16"):
    print(s, f"{zlib.crc32(s.encode()):08X}")
```
输出分别是 `54706054`、`1BBFA75E`、`89A3482C`、`FD9AF1E1`、`4C9BA961`；这里的类型名参与哈希。不是所有列都找到可信名字，剩余字段见 [[ACNH303_JSON_Rebuild/docs/08-字段数据字典总览]]。

## 4. Zstd → SARC → MSBT

读取 `Message/String_CNzh.sarc.zs` 时先检查 Zstd 文件头 `28 B5 2F FD`，用 `decompress` 解压得到 SARC；SARC 头 `SARC`、`SFAT` 节点表、`SFNT` 文件名表和成员内容。仓库 `parse_sarc` 检查边界和重名、限制成员数量。3.0.3 有 14 份语言档、各 133 个 MSBT 成员，合计 1,862 个 MSBT 文件。

MSBT 头 `MsgStdBn`，`LBL1` 是文本 label→索引，`TXT2` 是按索引排列的文字内容，`ATR1` 是属性段（目前仓库解析器只列出段大小，**没有**完整语义解码）。按 BOM 判断大小端；文本编码通常 UTF-16，读取 TXT2 的偏移/长度，不依赖文件名臆测名称。

```python
from pathlib import Path
from acnh_formats import decompress,parse_sarc,parse_msbt
raw=Path("e10617820db06889e1638499478da0de_NCA/1/Message/String_EUen.sarc.zs").read_bytes()
blob,method=decompress(raw)
manifest,members=parse_sarc(blob)
npc_msbt=next(b for member,b in members if member=="Npc/STR_NNpcName.msbt")
npc=parse_msbt(npc_msbt)
bylabel={entry["label"]:entry["text"] for entry in npc["entries"] if entry["label"]}
print(bylabel["ant00"])  # Cyrano
```

**注意**：MSBT 展示文字可携带 U+000E/U+000F 控制码，保留原文 `text_raw` 和可选清洗版 `text_plain`；不能直接删除未知标签而认为与游戏渲染等价。
