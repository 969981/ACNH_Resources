## Item grid
01A50240 -> 012E4D78 raw 8-byte record; 01A5033C -> 012E4F58 resolves extension records. Both select plane by request index; object base +0xc8+0x10*plane, pointer +8; index >7 fallback0, validity and scene checks separate. 01A4F798 checks plane pointer +0x60+8*plane and bounds. 012E4D78/012E4F58 local x,z subtract grid origin +0x10/+0x14; bounds use vtable +0x18,+0x20; bitset at +0x1b8 with width +0x1c8, height +0x1cc, count +0x1c0, index x+width*z. Set bit yields fallback, not necessarily physical occupancy. Data pointer via vtable +0x28 and buffer +8. Record 8 bytes.
FFFE signed -2 empty/invalid; FFFD signed -3 extension; 012E4F58 uses unsigned X offset byte6 and Z offset byte7 (u32+4 >>16 &255 / >>24), anchor=(queryX-offsetX,queryZ-offsetZ), bounds checked, returns anchor record and optional anchor coordinates. One-step resolution, no recursive chains asserted.
0277DA10 excludes -3,-2 first. Otherwise tests actual item table and optional other table; fallback special normalized ID F619..F61F. Thus 0148E51C count>3 is count of records accepted by this predicate on layer1, excludes extensions; not universal layer count, not guaranteed distinct ID count. No assumption about rare special IDs.

## Height
Original CRC32 names reproduced exactly: C187C516 = CRC32("Height f32"), B662662C = CRC32("RideHeight f32"). Both previously unknown hashes in ItemParam schema. 01AE8C70 reads C187C516, cache+0x28; 01AE8DB0 reads B662662C, cache+0xf0. 0149A6F0 explicitly reads both fields from ItemParam record lookup. Normal layer0 uses Height (item 0x2b56 special override 15). Layer1 resolves lower object, reads lower RideHeight and adds upper Height; special lower categories 0x15 and 0x17 alter baseline/limits, missing lower fallback differs. Quantize start/end via floor(value/5), selected branches cap end at7. Do not apply a single simplified formula to every category or equate collision height to rendered highest vertex.

Independent local extraction from previously accepted original BCSV SQLite (artifact 15000592353, SHA256 131b1f36cd0f113dfb12723141d2e592e917ce57c12d4d0214f12453b6c17522, integrity ok). 11178 rows, all finite; 406 placement types1..6, all RideHeight nonzero; support RideHeight 0.6908199787..30, Height 0.7512819767..40. Global values include negatives; preserve rather than clamp. Local height-evidence.sqlite3 729088 bytes SHA256 938adafbc385d31f449fccc40a4289946160037903eade321fe4a07eb165447f, integrity ok. No fresh source or native execution claim.

## Vertical grid

Wall checks in 0149A6F0 branch2..5 and ceiling case7 differ. Some wall checks also consult bitset bounded 0x120×0x100. Native 3D occupancy evidence, not mesh-based physics or player pathfinding.
